## Definitions

### Tactical plan

In supply chain management, a tactical plan is a medium-term plan that outlines the actions and strategies used to achieve the organization's overall supply chain goals and objectives.

Tactical planning typically covers a time frame of six months to two years, and it focuses on implementing the strategic plan.

In SIMCEL, it refers to the plans that are created regularly (weekly, monthly, and so on) and that are used to create the committed plan.

<Note>
Beyond the tactical plan, SIMCEL also features a **Budget Plan**, or strategic plan, aimed at setting broad business goals across 2 to 5 years and focusing on key areas like brand, channels, and regions.
</Note>

## Creating a new tactical plan

Click **+ Plan** to open the SIMCEL plan menu.

<Frame caption="The + Plan button opens the SIMCEL plan menu">
  ![SIMCEL toolbar with the + Plan button highlighted, opening the plan creation menu](/images/demand/tactical-plan-1.png)
</Frame>

To create a new tactical plan, for example a plan for February 2026:

<Steps>
  <Step title="Set the plan title">
    Set the title of the plan to **Feb 2026**.
  </Step>
  <Step title="Select the plan type">
    Select **Tactical plan**.
  </Step>
  <Step title="Select the forecasting method">
    Select the forecasting method. You can try the **Light Gradient-Boosting Machine (LightGBM)** method.
  </Step>
  <Step title="Select the plan period">
    Set the **Plan Period** to **Feb 2026 - Jan 2027**.
  </Step>
  <Step title="Add a description">
    Add a description. This is optional.
  </Step>
  <Step title="Create the plan">
    Click **Create**.
  </Step>
</Steps>

<Frame caption="Configuring a new tactical plan">
  ![New plan dialog with the title Feb 2026, the Tactical plan type selected, the LightGBM forecasting method, and a plan period of February 2026 to January 2027](/images/demand/tactical-plan-2.png)
</Frame>

The screen shows a loading page while the forecaster generates the demand projection for the new plan. This may take a few minutes.

<Frame caption="The forecaster generating the demand projection for the new plan">
  ![Loading screen shown while SIMCEL's forecaster generates the demand projection for the newly created plan](/images/demand/tactical-plan-3.png)
</Frame>

<Check>
Once the loading completes, you have successfully created your first plan in SIMCEL to forecast your future demand.
</Check>

The default scenario displayed is the **Forecast Base**, which shows the unbiased demand projection, free from any event influencing the demand.

<Frame caption="The Forecast Base scenario shown by default in the new plan">
  ![Demand chart displaying the Forecast Base scenario, an unbiased demand projection with no events applied](/images/demand/tactical-plan-4.png)
</Frame>

The **Demand Chart** widget shows a line chart with a time series of the demand and the total of the displayed period on the left-hand side for each scenario.

## Create a future demand planning scenario

<Frame caption="Event Management in the left panel">
  ![SIMCEL left panel with Event Management selected, where demand planning events are created](/images/demand/tactical-plan-6.png)
</Frame>

Open the **Event Management** page in the left panel and create your demand planning events.

### Create an event with one impact on sub-segments

Suppose you want to create an event where the demand of all beer products on the General Trade channel increases by 30% for the **Beer** category on the **General Trade** channel.

<Steps>
  <Step title="Name the event">
    Name the new event **General Trade Beer Demand Increase**.
  </Step>
  <Step title="Select the event type">
    Select **Demand Adjustment**.
  </Step>
  <Step title="Name the version">
    Name the version **V1**.
  </Step>
  <Step title="Set the period">
    Select the period from **May 2025** to **July 2025**.
  </Step>
  <Step title="Select the product">
    In the product search box, type and select **Beer**.
  </Step>
  <Step title="Select the customer">
    In the customer search box, type and select the **General Trade** channel.
  </Step>
  <Step title="Set the impact">
    In the **Adjustment on Demand** section, select **Increase** and set it to **30%**.
  </Step>
  <Step title="Save">
    Save the event.
  </Step>
</Steps>

<Frame caption="A demand adjustment event with a single impact">
  ![Demand Adjustment event form with the Beer category, the General Trade channel, a period of May to July 2025, and a 30% increase](/images/demand/tactical-plan-7.png)
</Frame>

### Create an event with multiple impacts on multiple segments

Suppose you want to create an event where the demand for Tiger Beer switches to Hanoi Beer in the Modern Trade channel:

- Decrease the demand by **15%** for the product **Tiger Beer** on the **Modern Trade** channel.
- Increase the demand by **12%** for the product **Hanoi Beer** on the **Modern Trade** channel.

<Steps>
  <Step title="Name the event">
    Name the new event **Demand-Switch**, select **Demand Adjustment** as the event type, and name the version **V1**.
  </Step>
  <Step title="Add the first affected segment">
    In the product search box, type and select **Tiger Beer**. In the customer search box, type and select the **Modern Trade** channel. In the **Delta Adjustments** section, set the value to **-15%**. Select the period from **May 2025** to **Jul 2025**, then click **Save**.
  </Step>
  <Step title="Add the second affected segment">
    Click **Add Impact**. In the new box, type and select **Hanoi Beer** in the product search box, and the **Modern Trade** channel in the customer search box. In the **Delta Adjustment** section, set the value to **12%**, and select the period from **May 2025** to **Jul 2025**.
  </Step>
  <Step title="Save the event">
    Save the event.
  </Step>
</Steps>

<Frame caption="The first affected segment: Tiger Beer on Modern Trade, -15%">
  ![Demand Adjustment event form with the first impact configured for Tiger Beer on the Modern Trade channel at -15% from May to July 2025](/images/demand/tactical-plan-8.png)
</Frame>

<Frame caption="The second affected segment added with Add Impact: Hanoi Beer on Modern Trade, +12%">
  ![Demand Adjustment event form with a second impact box added for Hanoi Beer on the Modern Trade channel at 12% from May to July 2025](/images/demand/tactical-plan-9.png)
</Frame>

<Frame caption="The Demand-Switch event saved with both impacts">
  ![Event Management page showing the saved Demand-Switch event with both segment impacts listed](/images/demand/tactical-plan-10.png)
</Frame>

### Create a scenario with one or multiple trade and marketing events

Add the events above to a new scenario called **Scenario 2 Events**.

Go back to the Demand Planning page, click **Add Scenario**, then click **Create a new Scenario**.

<Frame caption="Creating a new scenario from the Demand Planning page">
  ![Demand Planning page with the Add Scenario control open and the Create a new Scenario option highlighted](/images/demand/tactical-plan-11.png)
</Frame>

<Steps>
  <Step title="Name the scenario">
    Set the name of the scenario to **Scenario 2 Events**.
  </Step>
  <Step title="Select the events">
    Select the event versions **General Trade Beer Demand Increase** and **Demand-Switch**.
  </Step>
  <Step title="Save">
    Click **Save**.
  </Step>
</Steps>

<Frame caption="Assigning both events to the new scenario">
  ![New scenario dialog named Scenario 2 Events with the General Trade Beer Demand Increase and Demand-Switch event versions selected](/images/demand/tactical-plan-12.png)
</Frame>

The events are now reflected in the scenario's demand.

<Frame caption="The scenario demand reflecting the assigned events">
  ![Demand chart showing the Scenario 2 Events line diverging from Forecast Base where the assigned events take effect](/images/demand/tactical-plan-13.png)
</Frame>

## Select a scenario to be the execution plan

<Note>
This section guides you through converting a scenario of your choice into a plan that is used as the reference for the entire business.
</Note>

Click the three dots menu icon and select **Make Primary**.

<Frame caption="The Make Primary option in the scenario menu">
  ![Scenario three dots menu open with the Make Primary option highlighted](/images/demand/tactical-plan-14.png)
</Frame>

Once you have successfully selected the scenario as the execution plan, a **Primary** tag appears.

<Frame caption="The Primary tag on the selected execution plan">
  ![Scenario list showing the selected scenario labelled with a Primary tag, marking it as the execution plan](/images/demand/tactical-plan-15.png)
</Frame>
