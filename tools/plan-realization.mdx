title: "Plan realization"
description: "Compare any mix of datasets across a full fiscal year, with Year-to-Date and Year-to-Go breakdowns."
---

The Plan Realization report lets you compare any mix of datasets selected in the plan over an entire fiscal year and its Year-to-Date (YTD) and Year-to-Go (YTG) periods. It helps you identify gaps, assess plan adherence, and evaluate variances.

To access this tool, click **Plan Realization** under the Tools section on the left-side panel.

### Period logic

| Period | Definition |
|--------|-----------|
| **FY** | Set based on the workspace (for example, from January to December) |
| **YTD** | From the FY start month (for example, January) to the plan's start month - 1 |
| **YTG** | From the plan's start month to the FY end month (for example, December) |

In this widget, the plan's start month is applied for every fiscal year available when calculating all the YTD/YTG periods.

<Note>
**Automatic full-year stitching**: Where a selected dataset has no value for the past period, the report auto-fills with the Actual or Last Plan value.
</Note>

### Comparison engine

The report shows the absolute and percentage variances between the displayed and referenced datasets, so you can quickly see where you are on track, where you are at risk, and the magnitude and direction of each deviation.
