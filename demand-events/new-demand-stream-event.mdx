## Definition

A New Demand Stream event is usually created when you need to account for demand without prior historical data. In other words, it covers launching a new product or establishing a connection with a new group of customers.

A New Demand Stream event also refines existing demand forecasts for products that already have historical sales records. It lets you integrate your internal demand estimates (Sales Out) to adjust the baseline forecast.

## Creating a New Demand Stream event

Click **Event** in the left side panel to open the SIMCEL Event Management page.

<Frame caption="The SIMCEL Event Management page">
  ![Event Management page showing the event timeline and the list of existing events](/images/demand-events/new-demand-stream-event-1.png)
</Frame>

To create a New Demand Stream event:

<Steps>
  <Step title="Create the event">
    - Click **New**.
    - Select **New Demand Stream**.
    - Click **Add**.
  </Step>
</Steps>

<Frame caption="Selecting New Demand Stream as the event type">
  ![Event type selector with the New Demand Stream option](/images/demand-events/new-demand-stream-event-2.png)
</Frame>

<Frame caption="The New Demand Stream definition screen">
  ![New Demand Stream editor showing the impact definition area for the selected segment](/images/demand-events/new-demand-stream-event-3.png)
</Frame>

This screen gives you access to the definition of the new demand stream and its related impact on the selected segment.

## Create a New Demand Stream for a New Product Introduction (NPI)

<Note>
To create an event reflecting a New Product Introduction, update the master data beforehand to include the new product and its related data.
</Note>

Now create an event with an NPI on the overall business.

<Steps>
  <Step title="Name the event">
    - Name the new event.
    - Name the version.
    - Select the period.
  </Step>
  <Step title="Select the new product">
    In the **New product** menu, select a product reference.
  </Step>
  <Step title="Select the product proxy">
    In the **Product proxy** drop-down, type and select a product reference.
  </Step>
  <Step title="Provide the monthly demand">
    Provide the **monthly demand** for the new demand stream. You can type each month's value, or copy a row from a spreadsheet and paste it into SIMCEL.

    Click **Save** to save the impact.
  </Step>
  <Step title="Save the event">
    Save the event once you have finished editing.
  </Step>
</Steps>

## Create a New Demand Stream with multiple customer segment impacts

<Note>
You can also create an NDS/NPI event and set a specific impact per segment, which is useful when the product introduction happens differently across customer segments.
</Note>

<Steps>
  <Step title="Create the event">
    - Create a New Demand Stream reflecting a New Product Introduction.
    - Name the event and the version.
  </Step>
  <Step title="Add the first impact">
    - Click **Add** to set up a new impact.
    - Set up the period.
    - In **Target Customer Scope** under **Launch Definition**, select a customer segment.
    - Update the **Monthly Demand** value, or keep it unchanged.
    - Click **Save** to save the impact.
  </Step>
  <Step title="Add a second impact">
    - Click **+ Add** within this event to add one more NPI.
    - Enter the same product and product proxy information as the first segment, but select a different customer segment in the customer drop-down.
    - Define the monthly demand value for this extra NPI.
  </Step>
  <Step title="Save the event">
    Save the event.
  </Step>
</Steps>

</Frame>

<Warning>
If the chosen segment is unavailable for the proxy product — meaning the proxy lacks data or a demand pattern for that segment — no sales data is generated, even if you set a ramp-up period for that segment.
</Warning>
